# Apps/Tools to Install

- [Install IntelliJ](https://www.jetbrains.com/idea/download/?section=mac)
    - Our code editor
    - You will get a two-week free trial, but if you [apply for a student license](https://www.jetbrains.com/shop/eform/v2/students) you can get the Pro version for free

- [Install Advantage Scope](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest)
    - Used for viewing statistics and graphs about the robot (for example, the RPM of a motor)
    - Also useful for simulating the robot
    - [Read more about it](https://docs.advantagescope.org/)

- [Install Choreo](https://github.com/SleipnirGroup/Choreo/releases/latest)
    - Used to plan out autonomous paths for the autonomous period of the match ([what is an auto?](https://learnfrc.com/guides/getting-started/the-season-and-the-game/how-a-match-works))
    - Choreo helps us define trajectories for the robot to move along, like a line that the robot follows

- [Install PathPlanner](https://github.com/mjansen4857/pathplanner/releases/latest)
    - Used to plan out autos for the autonomous period of the match ([what is an auto?](https://learnfrc.com/guides/getting-started/the-season-and-the-game/how-a-match-works))
    - PathPlanner allows us to piece together paths from Choreo; for example, move along one path, then shoot, then move along another path. If you're interested in this, you can check the auto folder for more explanations
