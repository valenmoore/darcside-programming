# DARC SIDE Programming Guide

This repository holds all of the information we can think of that will help DARC SIDE programmers understand software for FRC, starting from the basics of Java and GitHub and going to advanced control systems.

You can find most of this information in the general folder. If you're just starting, look in the introduction folder and open a file like learn_github.md or learn_java.md. Each file will have some of our own attempts at explanations as well as some links to articles, videos, interactives, etc. You can use these however you want; there are no assignments, so just learn however you like to learn. If you have any questions, feel free to ask. If you find good resources to contribute, clone the repo and push them.
